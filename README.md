## Overview

EmoteSmith provides a browser-based workflow for preparing artwork used in Twitch channels. It creates the standard image size variants required for emotes and badges, allowing creators to produce correctly dimensioned files without installing a dedicated desktop program.

Along with resizing, EmoteSmith automatically compresses the resulting images toward the 25KB target. The tool covers three standard Twitch emote sizes and three badge sizes, making it suitable for streamers, moderators, and designers working on channel assets.

---

## What It Does

- Creates Twitch emote files at 112px, 56px, and 28px.
- Produces Twitch badge variants at 72px, 36px, and 18px.
- Compresses generated images automatically to 25KB.
- Works inside a web browser.
- Handles emote and badge preparation through the same workflow.
- Generates the standard size variants from a source image.
- Combines resizing and compression instead of requiring separate tools.
- Uses Twitch-specific dimensions as the basis for image preparation.
